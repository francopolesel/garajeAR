# GarajeAR brand assets

A minimal automotive identity for GarajeAR, using deep forest green, charcoal, and mint accents.

## Files

- `logo.svg` — primary transparent-background logo for light surfaces (vector, preferred for web).
- `logo.png` — high-resolution transparent PNG version of the primary logo.
- `logo-dark.svg` — transparent-background logo for dark surfaces.
- `logo-dark.png` — high-resolution transparent PNG version for dark surfaces.
- `icon.svg` — square app icon in SVG format.
- `icon.png` — 1024×1024 PNG app icon.
- `favicon.svg` — compact SVG favicon.
- `favicon.png` — 64×64 PNG favicon.

## Suggested use

Prefer SVGs in the web application for crisp rendering. Use `logo.svg` on light backgrounds, `logo-dark.svg` on dark backgrounds, and `icon.svg` for compact navigation, app icons, and social previews where only the mark fits.

## Suggested prompt for the coding agent

"Integrate the supplied GarajeAR brand assets throughout the existing application. First inspect the repository and existing design system. Use logo.svg on light backgrounds, logo-dark.svg on dark backgrounds, icon.svg for compact app-icon placements, and favicon.svg for the browser favicon. Copy the assets into the project's appropriate public/assets directory, update the document title and favicon references, and apply the logo consistently to the public landing page, authentication screens, application sidebar/navigation, mobile navigation, and any relevant metadata. Preserve correct aspect ratios, prevent stretching or cropping, use meaningful alt text where the image is informative, and use an empty alt attribute where decorative. Ensure the logo remains legible and appropriately sized across breakpoints and both themes. Do not recreate the logo using text, emoji, or CSS shapes. Do not replace the current design system or break existing routes. Verify the updated application with the available build, type checks, tests, and browser preview."
